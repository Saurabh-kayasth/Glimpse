## The icon

Kept simple, like other Mac app icons: a blue rounded square, one white folder, and an eye on its front, the same idea
as the menu-bar eye ("see inside folders"). It's readable down to 16 points. The first version (a folder, a cursor and
a preview panel with rows) was too busy, and was replaced the same day at your request. It's drawn in code so it can
be changed and regenerated (`swift tools/make-icon.swift`). macOS 26 adds its own glassy edge when it shows the icon.

## The README picture

There's no way to screenshot your screen from here, and a real desktop would show real folder names. So the picture
is made from a **made-up "Holiday photos" folder**: six drawn landscape "photos", a PDF itinerary, a packing list and
two subfolders. Glimpse showed its real panel for that folder (`--simulate-hover … --snapshot`), and
`make-hero.swift` placed it on a drawn desktop with its folder icons and cursor. The panel in the picture is exactly
what the app draws, previews included.

  [make-hero.swift](../../tools/make-hero.swift).
- **License: MIT**, added 2026-11-24 ([LICENSE](../../LICENSE), © 2026 Glimpse contributors). The README and the About
  window say so.
- **Install is from source** because Glimpse isn't notarized; the README says so and explains why it can't be on the
  App Store.
